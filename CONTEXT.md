# Current Project
German learning app for Jakub — a medical student targeting conversational fluency and German medical exams. Sessions are everyday conversations in /drafts, calibrated daily to active gaps, not strengths.

# What good looks like
- Each session targets the top open gaps from GAPS.md, not random topics
- Conversations feel natural and progressively harder — not textbook drills
- Medical vocabulary woven in organically where relevant, not isolated
- Corrections via recasting mid-conversation + 2-3 pattern notes at the end
- GAPS.md updated after every session: gaps closed when mastered, new ones added
- Difficulty adapts session to session based on observed performance

# What to avoid
- Generic phrasebook content with no real context
- Correcting every single error — focus on patterns, not one-offs
- Starting a session without reading GAPS.md first
- Fixed difficulty regardless of how Jakub performs
- Long grammar explanations before actual practice
- Repeating what Jakub is already good at
